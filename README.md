NBA Attendance & Team Performance Analysis
Project Overview

This project explores the relationship between NBA team performance and home-game attendance across all 30 NBA teams. Using Microsoft SQL Server and Microsoft Excel, I organized basketball data, calculated team performance metrics, and built visualizations to identify trends and compare teams.

Tools & Skills
- SQL Server Management Studio (SSMS)
- SQL calculations, sorting, and data analysis
- Microsoft Excel, formulas, and charts
- Data visualization and exploratory analysis
Project Objectives
- Compare NBA team win percentages.
- Analyze average home attendance.
- Explore the relationship between team performance and attendance.
- Communicate findings through charts.
Key Findings

The exploratory correlation analysis returned approximately 0.228, indicating a weak positive relationship between the two variables in this dataset. Team performance alone does not strongly explain differences in attendance.

Project Takeaway

This project helped me strengthen my SQL, Excel, data analysis, and visualization skills while working with real-world basketball questions.
